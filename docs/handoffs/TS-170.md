# TS-170 酷狗取源与跨平台录音匹配恢复

基线 `1837658352f85645aef0228435236b9584012f4b`，用户要求处理99首旧失败并查明原因；沿用音乐实现、提交推送部署授权。独立任务检出，保留其他产品及根未提交改动。

真实少量查询确认：官方酷狗HTTP CDN在强制HTTPS后证书校验失败，原协议Range返回206音频；部分手机接口对无损和普通资源均返回空地址，不能据此认定会员原因；跨平台结果被斜杠合并的歌手字段和专辑Explicit标记排除。重录版/翻唱依然拒绝。

复用既有Bridge、Catalog、Resolver、共享请求预算和下载归档。尊重酷狗上游明确给出的音频协议，保持主机白名单、无账号Cookie传输及TLS校验；按各音质对应哈希取源，识别缺少该音质和接口风控；Web扫码账号补用依赖已提供的签名songinfo路径。跨平台统一组合歌手与专辑提示标记，明确Clean/Explicit冲突仍拒绝。缺失资料只用共享音频哈希补齐，保留歌单源ID；未归档且非用户明确绑定的来源可合入唯一既有录音。匹配报告记录检索结果及拒绝原因，临时接口错误不再被其他渠道的权限错误遮蔽。

Windows初轮70用例发现资料补齐后未复用既有录音，已修正并覆盖既有文件/手工绑定保护。最终音乐发现114项含1项契约环境装配错误及5条环境跳过记录；HTTP9项用固定Git合同修正环境后全过，其他有效结果复用。Go7项通过，Ruff和diff检查通过；未修改前端。正式Linux候选与实机恢复尚待执行，不能以替身测试称已修复所有歌曲。

真实查询仅在既有容器中使用已连接账号和共享限流，未启动额外 worker；没有输出凭据或签名URL。私有证据在根 `.runtime/music-recovery-20261016/`。无数据库结构迁移和新依赖。
