## 结果与复用

订阅新增 `destination_mode=source|custom`。来源目录按 UP 主、收藏夹、合集/系列、稍后再看分类，包含稳定来源 ID 后缀；安全名称规则集中于既有 `destination.py`，预览和保存共用同一解析函数。首次确定来源子目录后持久化，改显示名或切到自定义再切回来源均不漂移；旧请求/旧订阅缺省 `custom`，省略路径时保留原已存路径，已排队任务保留原快照。

新增 `POST /api/web/media/subscriptions/destination-preview`，输入 `source/label/account_id/target_id`，可选 `subscription_id`（含 `null`）、`destination_mode` 和 `destination_subdirectory`；返回 `destination_mode/destination_subdirectory/destination_directory`。预览模式缺省 `source`，旧保存缺省 `custom`。投影增加来源种类、两种目录模式和各目标的 `destination_subdirectory_supported`；当前 AssetLibrary 不支持来源子目录，服务器明确返回 `409 destination_not_supported`。

`watch_later/self` 必须登记有效账号，经 `/x/v2/history/toview` 获取完整列表，核对明确的 `count/list`、数量、BV、重复和预算。缺失/不完整/认证失败保留已有成员基线。账号属于此来源身份，编辑换账号返回 `409 subscription_account_immutable`，另一账号新建订阅；这一语义已与 TS-143 前端和父级直接确认。

扫描、规则引擎、Repository schema 2、全局 DownloadCache/Retention、Organizer 与同卷硬链接继续复用。没有新成员表或缓存，没有改变媒体内部 BV/CID、NFO 或发布归属。

## 历史整理调用入口

父级历史分类直接调用以下纯函数，避免复制清洗规则：

```python
from services.platform.media.config import source
from services.platform.media.destination import source_subdirectory

relative = source_subdirectory(
    source({"kind": "uploader", "id": "946974"}),
    "UP主名称",
)
# UP主/UP主名称 [UID946974]
```

`favorite.id=fid`，`collection/series.id="mid:sid"`，`watch_later.id="self"`。输入名称可来自可信来源显示名或 NFO UP 主名称；输出只含相对目录，不传入或硬编码宿主根。后续文件重定位继续由父级独占 `import_relocation.py` 与对应 Repository 事务，不由此订阅功能自动执行。
