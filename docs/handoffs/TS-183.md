# TS-183 书籍订阅

用户要求把已接受的书籍参考页面融入现有天枢，书籍与视频、音乐同属“订阅”。基线 `425e2b7581a5681915972694ce3c9db30e9f8232`；独立分支 `codex/ts-183-book-subscriptions`，实现与验证均在同一当前对话完成。没有推送、NAS 部署、真实账号操作或模型调用。

## 实现与复用

- 原导航追加 section 8，显示在音乐后，保留旧 URL；沿用应用壳、tokens、Drawer、MediaController、同源登录与 CSRF。原型排版变为真实的搜索/试读/订阅/书库/书源/整理设置组件。
- 书籍领域放在 `media/books`，复用媒体 Repository 文档与任务表、幂等回执、任务/扫描租约、取消重试、受控路径和目录发布锁。原视频/音频 worker 保持原分工，独立书籍消费者从同一本账领取任务，避免书籍被音乐长队列饿死。
- 使用固定 LegadoParser 源码与许可证，适配跨平台 QuickJS/lxml 和有界 HTTP。JSON 文件/粘贴/集合更新、分组聚合、来源选择、目录/正文预览均走实际规则引擎；坏集合保留旧规则，本地启停选择保留。
- 持久订阅及增量缓存、原件导入、元数据候选与人工优先、完整/部分 EPUB、同目录原子替换与中断恢复。已缓存正文、完整旧成品和外部修改文件分别处理；没有把未配置或失败显示成成功。
- 新增五个固定运行依赖：quickjs、lxml、cssselect、jsonpath-ng、hjson；进入现有 pyproject、开发依赖和带哈希的运行锁。复用原有构建检查，不另建服务。文件名规范从音乐存储模块移至已有 destination 模块，音乐调用保留原名称及行为。

配置、数据归属、使用步骤及兼容范围见 [书籍订阅说明](../platform/books.md)。
