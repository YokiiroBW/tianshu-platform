## 主要变更

- 独立 `actor_capabilities` 模块：精确候选校验、专用 Companion `actor.capabilities` 身份、当前角色版本、五种操作、有限错误 envelope。
- `plugins/actor_bridge.py`：显式 character scope / action entries、配置版本、实际 handler/schema/账号可用性、回执所有权和去敏窄投影。
- 对话/后台统一 principal + 原意图键；unknown 保留原 invocation，显式 reconcile 使用原 handler 且严格匹配原实例配置。get 返回原历史 revision。
- 原执行器新增角色 authorizer 的 child action / Host jobs 回调检查；角色 jobs 的 get/cancel 不能跨角色或绑定。角色 schedule.put/remove 不放行，因为原实例调度器不能保留角色身份。既有管理员和调度器路径保留。
- 修正原账本尚在 accepted、未获得实例锁的写调用取消结果：`not_applied`；读操作仍 `none`。取消时清理未进入执行 finally 的 authorizer。
- 原插件界面增加现有角色列表和明确动作选择，继续使用实例配置管理账号与凭据。浏览器列表读取、保存保持原 Cookie/CSRF/管理员配置权限。
- 公共 `service/server/auth` 仅装配；actor 错误使用独立 `execution` 字段，受理后异常保留 unknown/completed，原 HTTP/BotDelivery 行为回归通过。

运行细节和消费方接入见 [角色调用插件能力](../platform/actor-capabilities.md)。
