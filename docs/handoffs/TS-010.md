## 已完成行为

建立 React 19.3 / TypeScript 7 / Vite 8 的单一根清单和 npm 锁。统一八个目的型导航、二级地址边界、工作台、接入准备筛选、手机导航抽屉与外观抽屉。连接尚未配置，界面没有假角色、假任务数量、假设备或业务成功回执；输入无法匹配连接说明时呈现真实空结果。

单一 CSS 令牌承载认可的银蓝/淡紫/浅粉渐变、适度毛玻璃、实色正文面板、浅深主题、文字、间距、焦点和动效。Docker 展示基础为蓝黄红灰细轨；运行/健康需要不同文字，选中底色不覆盖轨道。没有复用旧绿色 `--ok`。状态语义映射留给有合同和观测证据的后续连接器任务。

小屋独立懒加载，只有未接入入口，不加载 WebGL 或实现 TS-011 场景。其余未实现业务共用未配置页面，不制造模块空壳框架。导入延迟显示加载中，导入失败保留导航且可重载恢复；无效地址可返回工作台。外观偏好本地保存，被禁用时明确提示并保留当前页功能。

导航与外观控件支持键盘，抽屉循环 Tab、Escape 返回触发点，路由切换焦点到正文；系统减少动态始终优先，支持减少透明度。网页不包含实时语音、观影、媒体权限或业务请求。
