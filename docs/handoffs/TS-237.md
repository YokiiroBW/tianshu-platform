## 实际变更与复用

实现独立插件包和实例管理、版本缓存与依赖环境、Python 工作进程、标准动作调用、加密实例密钥、KV 状态、工作区绑定、持久执行意图与分阶段回执、取消、检查点、显式恢复/核对、周期调度、版本迁移及失败恢复。卸载保留数据、历史、缓存与外部资源。

`tianshu_plugin` 是可单独构建的无第三方运行依赖 Python SDK，包含上下文、动作声明、受管任务、生命周期与页面桥。宿主通过有界 stdio JSON-RPC 与工作进程通信，不在主进程导入插件代码。内置回声与 HTTP 查询插件都可实际安装运行。

网页新增真实 `/#/plugins`，包括安装来源、实例配置与只写密钥、动作参数表单、任务与恢复、日志、工作区绑定、版本和独立页面。复用现有登录 Cookie、CSRF、operator 权限、HTTP transport、`requestId()`、主题令牌和懒加载模块注册；没有增加密码解锁步骤。页面采用专用响应与隔离 iframe，单次票据绑定会话，主站 CSP 保持原策略。

服务复用 `LocalWork` 和现有注册数据库后端，插件台账支持 SQLite 与原生 PG；任务中心只读投影同一执行台账。五个能力 `state.kv`、`http.client`、`secrets.read`、`jobs.manage`、`notifications.emit` 提供十二个校验输入/输出的操作，控制面从同一注册表生成 OpenAPI 3.1。插件写操作由文件锚点上的单一监督者执行，其他服务入口仍可提供原有 API。

本批运行 Schema 沿用 TS-167 候选，不修改根已发布合同，也不把本地代码交付称为跨产品合同已冻结。配置和使用说明见 [插件运行说明](../platform/plugins.md)。

### 既有回归与修正

按受影响入口组合执行旧套件 185 项，初次结果为 **3 失败、25 错误、1 跳过**，原始记录 `.runtime/plugin-regressions.log` 和 `.runtime/plugin-regressions.json`。发现并修正了本批接入造成的两类问题：第二个服务入口被插件监督者锁阻止启动，以及任务水位夹具未登记新只读来源。对应六项 HTTP/原生端口/任务中心回归随后全部通过，记录 `.runtime/plugin-followup-regressions.log`。没有将这些分组结果冒充完整套件全绿。

余下记录包含原生 capabilities 错误码断言、探针读取期间后台媒体推进导致 SQLite 字节变化，以及 Windows 临时 SQLite 文件占用清理。TS-231 交接已有同类基线证据；本批又在原精确基线环境独立复现媒体探针字节变化失败。未对每一个旧错误逐项复现，未扩展修改无关行为，也没有在修正后重跑整组 185 项。

## 未完成与限制

- 插件是安装者信任的代码；独立进程不构成 Python 安全沙箱，也不提供容器资源隔离。当前单文件锚点监督者不支持多主分布式调度。
- 命令/模型工具目前仅声明导出，尚未接入聊天路由；事件、完整消息桥、群管理、模型、文件、下载等提供者与 MoviePilot 业务插件未实现。不能声称兼容 AstrBot 等插件生态。
- Git 固定提交与带 hash 的依赖安装路径已实现，但未实际访问外部仓库/索引安装第三方插件；Linux/Docker 信号、NAS 挂载和真实外部服务未验收。
- 配置表单支持常用 Schema 字段，复杂前端可使用独立页面；页面资源需预打包。当前为轮询，没有 SSE 或文件选择提供者。
- 本地活动库、加密密钥与需要恢复的包缓存须配套备份；任意插件私有文件及外部业务迁移不属于宿主管理的 KV 回滚。现有 NAS 分层/备份工具本批未改。

后续按完整功能块接入聊天命令/工具和事件提供者，再使用真实业务插件检验扩展合同；生产发布应另核对最新历史、部署配置、包缓存机械盘路径和恢复输入。
