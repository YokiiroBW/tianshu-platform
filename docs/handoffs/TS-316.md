# TS-316：群记忆页面、角色记忆权威与后台身份

基线为已发布 `506a82062166cef457974ef9b95789010e3435d0`，沿用 TS311 物理 worktree，
新分支 `codex/memory-extensions-20261026`。先将已验收 AL07
`90c0d44fc5d244e91ea4665e59e18e18a607e3df` 合入，整合提交
`209df023f223027880d597191ac3a49dcca1459c`；没有重做能力执行器。

本功能块实现现有 MemoryPage 内的群目录、互动图、二维话题点云、热度时间桶、共享画像及
按需历史分页/原话邻读。沿用现有 Web 登录、角色选择、Origins 和 Memory browser。
Origins 对明确登记的只读 WEB entry 使用真实 QQ 渠道的当前 conversation 映射，保留真实
WEB 身份；没有扩大普通 entry、QQ 身份或模型输入的权限。读取前后核对当前角色、入口、
群映射及授权；任何已知遗忘 alias 都能过滤相应原话和邻近消息。

新增 actor memory authority 只负责当前角色与受众授权。实际阅读证明仍归 Comp/Knowledge，
用户记忆和 BOT actor 记忆不合并。ProviderAuthority 允许独立、受认证的后台 caller，保持
原 turn/version/caller 绑定；Gateway 侧配套在 TS317，未改槽位、排队容量或生产超时。
重复的候选合同加载复用单个 CandidateProtocol，AL07 pin 保持原值。

配置和 API 见 [运行接线说明](../platform/group-memory.md)。当前是本地候选，尚未推送、部署
或启用真实 Chat/QQ/外部模型连接。
