## 修复的进程与聚合边界

Windows venv launcher 会在 asyncio 返回根进程前生成 base-python；运行后绑定 Job 虽然 API 成功，已存在的后代仍可能在父退出后存活。现在先 `CREATE_SUSPENDED`，绑定 kill-on-close Job，再通过根主线程恢复。合法 venv 命令保持，未换 base-python 掩盖问题；保护／恢复失败先回收挂起根。父先退出、超时后代回收及恢复失败根回收的实际 Windows 测试均通过。

实际 OpenSSH 在限制环境中需要 PROGRAMDATA；已仅追加这个系统变量，未继承整套用户环境。多批指标保留任何批次 partial／reason_codes，并取最早 observed_at；首次、计数重置、过长间隔不填零。取消后的 LocalWork 事务仍可能完成，因此观测缓存也在事务内按连接修订拒绝退役结果覆盖新结果。
