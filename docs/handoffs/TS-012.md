## 目标与变更

实现单个模块化 Python 平台后端，SQLite/WAL 隔离持久化。消费合同 1.0.0（主发布 `102d347`），manifest LF-normalized SHA-256 为 `81e6cc4ddef7c6f82e055d4cb04b090db036dd5c52763473ce697aa02db478a1`，启动检查 manifest 与五份 schema。没有新增共享 wire 或本地 schema 副本。

- 仅公开现有 `POST /internal/v1/origins/resolve`、`POST /internal/v1/model-config/snapshot`，loopback 本地演练，浏览器 Origin/Cookie 拒绝。缺失凭据/配置明确不可用。
- 服务身份来自部署登记及当前独立环境凭据，local CLI 操作者身份与 web 账号由服务端配置核验，payload 不授予身份。实际签发随机来源引用并落库，校验到期、撤销、入口摘要、账号/角色/受众以及独立 caller→receiver 代理路径。
- 同一 ref 的 dialogue 代理路径逐条登记；`authenticated_service` 是业务调用服务，`audience_service` 是接收者。当前 wire 无 operation，issuer 只核验 dialogue 授权域，register/select 具体操作留给接收方。config.snapshot 使用独立用途和版本授权。
- 受信内部 prepare/confirm 端口支持 memory.register、memory.resolve（已有/未登记账号）及 companion.ingest 回执关联。首次 person/conversation 可 null；人物绑定由 memory 回执确认、conversation 由核心回执确认。两种回填顺序、原账号/channel/actor、请求关联、主体冲突、版本冲突和超时均检查；核心返回的 person 只作为一致性核对，不能先替代 memory 绑定。
- 操作者原子发布配置，校验 provider/workload 唯一性、绑定模型、登记目标与凭据命名空间、能力登记、有效期、版本递增和同版摘要。同版异内容拒绝，旧版指定读取保持原内容，到期/撤销拒绝；重启保留版本与撤销。脱敏 view 不含 URL、credential_namespace 或完整 credential_ref。
- 仅登记三个已实现能力，任务只保留 owner/job 投影、版本、游标、新鲜度；owner 自己认证写入投影，平台不执行/取消任务，不生成假设备成功。

实际接点和完整运行方式见 [平台后端运行](../platform/runtime.md)。新增 Python 清单与解析固定依赖；保留前端 README/AGENTS 原命令，不改应用壳、小屋、令牌、npm 清单/锁或任何前端源码。

## 未接入项与下一步

- 本地 CLI 认证不代表真实网页登录、QQ/TG 或 NoneBot issuer 接通。对话演练来源明确 `issuer=platform`。正式来源签发、回填、撤销/续期及 web 管理公共协议由协调者决定，本任务只提供受信内部端口，不猜 URL。
- `verify_current_sources` 只核验已登记当前入口、scope 元组、消息修订/墓碑，使用已认证 companion 发布者，不重用过期用户 ref。返回明确的 `archive_verified=false`、`scope_version_verified=false`；未知来源或未接归档权威拒绝。它不是 Memory 完整 SourceAuthority，不能替代核心 turn/input revision、记忆 scope_version、原文/归档回执核验。未跨项目读平台内部表；正式适配、撤销传播与事务衔接尚待双方验收。
- 真实平台→网关→录制上游是局部子链，**不是完整 L0/L1 或真实模型验收**。下一步由协调者接入实际 companion/memory 的来源回填与范围验证，再做 TS-050。网关缓存仍受 usable_until 和已收到撤销约束，不保证离线即时撤销。
