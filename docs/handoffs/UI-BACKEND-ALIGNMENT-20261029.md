基线为已部署 Platform `940f93cedb5a9ea62f48c5f9bc2ef7d1e0d410a5`，分支 `codex/ui-backend-alignment-20261029`。对照统一 R19 的 Companion `a22924323a6b1b28ab166833df165cf96e351b6e`、Memory `9b900a6a35808cd9dd064f87564e42dc7b629620`。原 TS311 分支、未提交文件及根目录修改保留，使用已有隔离发布 worktree。

## 核对与调整

- 本人记忆已有时间线、回顾、来源撤回检查和学习进度；补出回顾中的约定期限，日期经过不标作完成。
- 用户共享画像和群画像遗漏新版整理信息。现在复用原 `MemoryRecords` 展示依据时间、状态、更新数量、关联数量、保留信息；事实适用条件仍可查看。共享范围不额外读取私有原话，缺少可展示摘录时明确说明。样式归属于记忆组件，不依赖先访问本人记忆页面。
- 当前后端日程入口仍是 `life/today` 的滚动计划与 `life/timeline` 的实际经历；现有 UI 已区分 baseline/gateway、生成状态、计划阶段和实际记录。未创建平行日历或把计划当成已完成工作。
- `concern.save` 已支持跟进时间与有效期，原 UI 仅透传既有值；补充显示、编辑和清空日期，标明输入使用本机时区。沿用原版本检查、回执和不确定结果重试。
- 当前目标、此刻状态、短期感受每 15 秒刷新。复用 `useLifeResource`，后台隐藏时暂停，重入时重读，角色变更和卸载时取消请求；慢请求不被定时器反复中止。活动及关注列表补手动刷新，不刷新掉未提交表单。
- 角色记忆的兴趣历史、来源影响、更正/遗忘、部分覆盖，以及实际阅读/创作进度入口已接入，无须重复实现。保留原鉴权、本人/他人/群/角色记忆边界和后端业务逻辑。
