# TS-412 原turn动态模型租约恢复

基线 `c591a5ddda34b31cd0e9e55f46cd7d50fae36dae`，分支
`codex/ts412-original-grant-renewal-20261029`。

原 `ProviderAuthority.select` 对已有turn只接受publication剩余大于65秒，过期后
再次提交完全相同SelectionRequest也永久410，阻断原任务的正常恢复。

本卡复用原select与publication创建逻辑。在原config.select身份核验、角色有效性
及原scope_digest/caller/workload一致的前提下，已有未撤销publication剩余不足
65秒时核对原provider_id/revision仍当前且启用、来源启用并保留原凭据；复用该
精确pin足够寿命的publication或创建新版本，仅CAS更新当前turn的grant version。
不延长旧publication、不更换turn/provider/revision，不改变其他turn的授权。
原publication撤销、provider修订/禁用、scope变化或身份失效继续拒绝。创建和续期
共用同一小方法，原65/120秒边界与最多一小时寿命保持；无接口、合同、DDL或配置变更。

Companion使用原SelectionRequest重新select由协调者/TS408负责，本卡不恢复模型
unknown结果、不重放原请求、不发真实模型或QQ消息。

publication保持；剩余65秒续期；身份/scope/撤销拒绝；provider修订/禁用拒绝。
复用原pin/角色覆盖和后台实际HTTP身份两父，计划最窄共6节点。
