# TS-113 网页访问方式

基线 b98c8a2a09279125df08bd48f3fab3422f3de165，分支 codex/ts-113-web-access。用户授权协调者实施，不再派 DSH。

新增独立公共网页监听与 web_access 叶子模块；内部服务端口继续 TLS，网页端口拒绝内部 RPC 与健康诊断。设置页面沿用 React/Vite 与既有样式，支持 HTTP、直接 HTTPS、反代外部地址。证书来自部署白名单并做离线握手检验有效期/SAN/私钥。严格 Host/Origin/CSRF、口令限流保留。反代不信任来客 Forwarded 头，按登记 origin 设置 Secure Cookie。

配置以管理员口令复核、版本比较、原子替换/fsync 保存到私有数据目录；明确待重启，当前连接不热切换。未知/损坏文件拒绝启动，不假装成功。部署端口与证书文件不从网页输入，未提供自动证书签发、DNS 或 VPS 管理。

实际验证：受影响 HTTP/TLS/runtime/新入口套件 183 项中 182 通过，网关联合项因未设源码路径跳过，随后设置集成源码路径单独补验通过；旧网页登录 8 通过；新增过期证书拒绝 1 通过；合计 192 个不同后端用例通过。新访问套件最后 8 项全过。Ruff 通过，TypeScript 检查与 Vite 构建通过。桌面/手机 Playwright 投影测试 2 通过（明确替身 API，非 NAS 证据）。构建保留既有小屋大包提示，未改小屋。

实际 NAS 部署、公开 IP 浏览器与长期运行另在协调仓库记录，本交付不作已部署声明。读取已有日志/恢复证据不会把它们改写成新入口验收。运行设置需随数据目录备份。


NAS s 浏览器返修：HTTP 登录/已有真实模型回执可见，但发送实际触发 crypto.randomUUID 不可用；随后 platform 报 log_flush_timeout，网页转503。未判网页通过。改为共用 Web Crypto getRandomValues UUID v4（聊天/模型发布/家庭控制共用）；新增显式 diagnostics.durability_timeout_ms，默认250，允许250–5000整数，NAS验收选择2000。仍先fsync后确认，超时仍停止接纳，不采样、不重发、不循环恢复。新增2项预算/真实慢fsync验证及移除randomUUID后的浏览器投影流程（含其他匹配用例共8项）通过；TypeScript/构建通过。新NAS固定源复验待记录。
