# TS-113 网页访问方式

基线 b98c8a2a09279125df08bd48f3fab3422f3de165，分支 codex/ts-113-web-access。用户授权协调者实施，不再派 DSH。

新增独立公共网页监听与 web_access 叶子模块；内部服务端口继续 TLS，网页端口拒绝内部 RPC 与健康诊断。设置页面沿用 React/Vite 与既有样式，支持 HTTP、直接 HTTPS、反代外部地址。证书来自部署白名单并做离线握手检验有效期/SAN/私钥。严格 Host/Origin/CSRF、口令限流保留。反代不信任来客 Forwarded 头，按登记 origin 设置 Secure Cookie。

配置以管理员口令复核、版本比较、原子替换/fsync 保存到私有数据目录；明确待重启，当前连接不热切换。未知/损坏文件拒绝启动，不假装成功。部署端口与证书文件不从网页输入，未提供自动证书签发、DNS 或 VPS 管理。
