基线 `da70adf28ea20f4bf913114896092c4ec101e9aa`，分支 `codex/al-core-platform-20261028`。本卡为隔离本地候选，未推送、部署或访问生产数据。

## 交付与归属

- 原 LifeWorkspace 新增“经历与记忆”，展示经历、认识、偏好、反思、自传、当前/替代/淡出/撤回状态及长期兴趣变化。默认展示能读懂的正文和状态，来源、依赖及 coverage 在详情中展开；经历分实际数字行动、观察、转述、虚构，并区分计划、执行、完成、失败与未知。
- 原 LifecyclePanel 消费 Companion `autonomy` 真实投影，展示目标、选择原因、步骤和下一步；活动/concern/reading 展示原来源与 checkpoint。原 AL13 日记来源、真实/虚构与时间窗保持，不另造日记或心声数据。
- 更正与忘记直接走 Memory 原 actor 域。更正保留替代历史；忘记可查看依赖影响，不另加确认弹窗。角色记忆与用户记忆分开，用户页仅增加导航说明；未改用户提取、事实、检索、表或接口。
- 历史导入复用 Life `actor-memory.import`，用户选择 activities/writing/images/contacts，一批最多 32 项、显式继续下一页、`expected_version=0`；不自动扫描。关闭页面不改变后台生活。
- 角色切换由原 LifeWorkspace key 卸载旧资料；隐藏页面中断读取，重新可见从 owner 重读；无浏览器计划权威、无新增轮询器。来源/权限变更隐藏旧记录。写 ACK 失败保留同语义 client_id 重试，成功后重读服务端状态。

## 后端接线与授权

新同源 `/api/web/actor-memory/{list,interests,episode,impact,revise,forget}` 沿原 Cookie/CSRF/Origin/session 验证。`WebActorMemory` 是窄 owner 客户端，没有数据库。actor、role_version、management/actor_only context、预算由服务器构造；浏览器不能提交 token、origin、scope 或服务地址。

复用 `RoleRuntime.managed_actor` 统一核对原 role.manage、当前 operator 所有权、active/enabled 与 memory.read/write；Life 与 Memory 页共用，不相互反向调用。请求前后重核角色及 session。禁写角色的 impact 不显示可更正/忘记。原 ActorMemoryAuthority 仅把新操作归入既有 memory.read/write，不新增权限。

autonomy 属管理读取：原 WebLifeManagement 在持有角色管理权和 memory.read 时，把服务端 scope 设为 None，沿既有 management_read/core 管理读凭据取得 actor-only 目标原因；普通用户 scope read 不变。历史 import 同样前后核对 owner 与 memory.write。

Memory owner 请求走既有 `role_runtime.memory.base_url/token_env/ca_file/timeout_seconds` 和既有 platform service caller，不借 Companion 或 web_memory/browser 身份。部署协调者须在该 token 已对应的 Memory caller 上显式登记 `actor_memory_operations` 的 `manage_list/interests/get_episode/memory_impact/revise_memory/forget_memory`，保留原 `allowed_actors` 或 runtime role 准入和角色 actor_check。本卡没有读取真实配置/凭据，因此不猜生产 caller 名；测试使用 `TS396_MEMORY` 合成 token。无新配置字段或新 token。

返回绑定 request/actor/role/context，写回执还绑定 command/idempotency key，经历绑定精确 ID/revision。get_episode 浏览器投影仅保留 summary/provenance/relation/outcome/occurred_at/learned_at/content_reads，去掉 source_constraints/access_version/generation 等内部证明。旧用户 MemoryContext pin 不变。
