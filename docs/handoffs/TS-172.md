## 边界

真实路径读取使用已部署版本的原生只读歌曲接口，歌单操作继续用 Subsonic；凭据/会话不进入日志或数据库明文，接口失败保留未确认状态。实现依据：[Navidrome 0.64.2 路由](https://github.com/navidrome/navidrome/blob/v0.64.2/server/nativeapi/native_api.go)、[文件模型](https://github.com/navidrome/navidrome/blob/v0.64.2/model/mediafile.go)、[认证](https://github.com/navidrome/navidrome/blob/v0.64.2/server/auth.go)。
