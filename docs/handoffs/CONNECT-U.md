## 第二批：外部连接管理与 Memory 回包校准

- 设置 → 连接新增管理员外部连接面板，仅管理 AssetLink 和 Home Assistant 固定服务。管理员密码二次解锁；地址、实体、服务凭据及自签 CA 分别编辑，凭据与 CA 均显式保留、替换或清除。保存带预期修订与请求 ID，成功只标“已保存、尚未检测”；管理员主动点击后端固定只读检测才显示实际读取结果。失败、未授权、未配置与管理权限不足分别提示。天枢内部服务没有地址或 token 输入。
- 浏览器只读取服务端返回的配置摘要，服务凭据和 CA 不回显。检测结果带全局修订；若与当前配置修订不一致则显示“检测已过期”，不把旧成功读数称为当前已连接。当前保存会话的原解锁期限由后端保留，其他会话的解锁失效；最终以 B 固定实现复核。
- Memory 概览改用已发布的 `memory_group_count`、`counts_truncated`，截断时显示“至少 N”，不再伪造人物总数；主体组计数同理。扫描上限可能产生空页加非空游标，页面保留继续读取入口，不误报目录已空。

## 独立审查后的竞态修正

- 外部连接的一次检测回包不能单独宣称成功；先刷新管理视图，要求当前全局修订与该连接的检测回执修订均等于本次结果，且状态一致。刷新失败或修订已变时不显示成功提示。合成并发改配置和刷新失败用例在桌面/移动共 4 通过。
- 项目和角色选择变化时同步失效旧请求、递增范围代数并清除旧正文/已发布日记；后续读取继续在受控 effect 中启动。延迟释放旧项目文档与旧角色日记正文用例在桌面/移动共 4 通过。此为审查提出的竞态防护，未以旧提交做可控复现。
