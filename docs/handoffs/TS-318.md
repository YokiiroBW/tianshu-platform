读前后复用原 authorizer/配置 revision，原 redactor 在新端口结果回 worker 前去敏。结果经插件 output schema 和原 ledger 保存，同意图重试/重启仍用原回执。候选仅有目录/检索片段、owner locator 与描述版本，`seen_state=unknown`；AL04 仍是唯一阅读历史权威，本卡只接受既有排除键，不写“已看”。
