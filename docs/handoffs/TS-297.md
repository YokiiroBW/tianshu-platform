# TS-297 管理员密码最少八字符

基线 `2943569e191000431b67e22f06780fd35f862249`。用户在迁移后的 `.230` 登录页确认应允许至少八字符。此前实际镜像 `ece1a045` 仍固定十二字符；相关 Git 历史未找到已发布的放宽版本，不能据此断言迁移覆盖了先前修复。

长度规则归入既有 `web_account.valid_password_length`，账号创建、接管、登录及模型、访问设置、外部连接、家庭和 Bot 管理解锁共同使用 8–256 字符。前端共享 `passwordPolicy`，CLI 和说明同步。scrypt 格式、现有账号、权限、内部服务令牌、限流、CSRF 和会话语义保持。

已有真实 HTTP 账号测试改用八字符合成密码，覆盖首次设置、持久化、接管替换、登录和模型解锁；增加七字符及超长输入拒绝和较长旧密码验证。浏览器真实后台测试使用八字符，覆盖桌面/手机创建、接管和重启后登录；首次设置断言对齐现有独立账号页面，不再查找已取消的顶部导航。

当前验证：Ruff、TypeScript、Vite 构建通过；四个桌面/手机真实后台浏览器流程通过（接管二项以及修正旧导航断言后的创建二项）。Windows 后端初次缺少依赖，补齐后宽泛 web 测试仍因未配置 TLS 测试解释器及 Windows SQLite 文件清理出现环境错误；这些失败保留于本号运行目录，不能记为通过。Linux 候选镜像回归和实际发布结果由后续交接补充。

部署授权来自同一聊天的 `.230` Docker 迁移及本次八字符修复请求。生产更新仍待完成；不使用或修改真实用户密码、不发送测试 QQ 消息、不调用真实模型。
