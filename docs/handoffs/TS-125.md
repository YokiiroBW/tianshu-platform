## 实现与复用

复用现有 `ProviderCatalog`、加密与 SQLite 事务、模型修订、测试回执、管理员授权和运行模型签发。新增 `provider_sources.py` 负责供应商连接及其模型归属，连接值与执行上下文移至 `provider_values.py`，原公共导入继续服务既有调用者；没有新增依赖、独立凭据库或网关协议。

设置页左侧管理供应商，右侧编辑一份地址和 Key，获取目录后搜索、多选或逐个添加，也可手动填写模型 ID。模型各自拥有名称、类型、启停、测试和默认选择；供应商连接改动作用于其所有模型。模型列表内部滚动，手机操作按钮两列显示。移除被此页面替代的独立组件夹具与废弃样式。

“模型功能分工”及角色独立模型继续引用稳定的模型条目 ID，显示供应商与模型名称。对话、日记、记忆整理使用既有实际调用链；工具、代码、网页搜索保持原来的预配置状态，页面明确自动消费者尚未接通。嵌入、重排序在记忆检索中引用同一供应商下的相应类型模型，不再复制连接或 Key；使用原 Gateway 适配器测试与执行。模型修订参与检索指纹及嵌入空间，换模型后不会复用原向量空间。

旧单模型数据在首次打开时先生成 SQLite 备份，再拆分到供应商和模型；保持原模型编号、修订、默认、角色/功能绑定、测试与已签发版本。不按相同地址猜测合并旧连接。旧独立检索配置保持可用，切换到共享模型时清除其旧密文。升级与回退要求见 [供应商说明](../platform/provider-sources.md)。本批只迁移临时合成库。
