# TS-124：订阅独立子目录与视频复用展示

基线：已部署 Platform `fdd4be0b3b4139eaf87889d2178bc13de607804a`。分支 `codex/media-global-reuse-frontend-20261012`；本交接与前端实现同一提交，完整提交 SHA 由协调交付记录索引。

## 实现与复用

复用现有 `SubscriptionsPanel` 三步编辑器、`useMediaController` 保存/错误/幂等链路和媒体 Playwright 夹具，没有新增后端接口或依赖。新建与编辑的“媒体库与预览”步骤提供“整理子目录（可选）”，显示所选目标根目录与子目录组成的完整路径。收藏夹、UP 主、合集和系列共用此流程，可以同一媒体库不同子目录；留空保存空串、旧投影缺省也为空串，继续使用原根目录。

`destination.ts` 集中处理目录输入的展示规范化和路径拼接，反斜杠统一为 `/`、整体前后空白去除；只就绝对路径、空层级和 `.`/`..` 给即时输入提示。文件名兼容、长度及文件系统验证归后端，`invalid_destination_subdirectory` 和既有 `unsafe_library_path` 通过原错误链路显示，失败时保留编辑内容。

订阅列表显示整理目录，并可按目录查找。编辑说明明确下次扫描会将现有成员整理到新目录，已入队任务继续使用旧目录。下载列表与详情仅读取任务保存的 `destination_directory`，不根据后来修改的订阅猜测位置；旧任务缺完整路径明确显示未提供。只有后端 `download_reused_cids` 非空才显示实际复用数量，通用说明为相同视频、分 P 和画质复用已有有效下载、各目录分别整理。

写入范围限于 `apps/web/src/features/media/`、`apps/web/tests/media.spec.ts`、`apps/web/tests/media.fixtures.ts` 与本交接。未改后端、锁文件、应用壳、全局主题和根任务板。
