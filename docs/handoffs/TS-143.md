## 完成内容与复用

复用原三步订阅向导、`AccountField` / `TargetField`、统一主题、媒体请求取消及目录展示函数。把既有编辑器移至 `SubscriptionEditor.tsx`，订阅列表保留在 `SubscriptionsPanel.tsx`；来源命名规则仍由后端拥有。

新订阅默认 `destination_mode=source`，自动目录覆盖 UP主、收藏夹、合集（含系列）、稍后再看。可切换 `custom` 沿用手填相对子目录。旧订阅缺省 `custom`，保留原子目录；已有 source 订阅编辑显示名不生成新路径，切换目标只替换根目录。保存、列表查找和状态事实同步显示目录方式与完整目录。

稍后再看直接提交 `source={kind:"watch_later",id:"self"}`，要求有效账号，不显示 ID 输入。沿用后端既有来源不可变规则：编辑时来源类型 / ID 固定，稍后再看账号同时固定；显示“此订阅跟随该账号的稍后再看，其他账号可新建订阅”。普通来源仍可选择账号。

AssetLibrary 目标明确显示不支持来源自动归类，使用 `custom` 空子目录仍按原资产库管理语义工作。切换目标保留用户的自定义输入。目录只读后端投影与预览，没有硬编码 NAS UNC / 宿主目录；容器或物理挂载由父级安排。

## 已确认接口

`POST /api/web/media/subscriptions/destination-preview`：

- 输入：`source`、`label`、`account_id`（null / string）、`target_id`；可选 `subscription_id`（null / string）、`destination_mode`、`destination_subdirectory`。
- 返回：`destination_mode`、`destination_subdirectory`、`destination_directory`（AssetLibrary custom 空目录可为 null）。
- source 保存可带预览子目录，实际生成和持久化仍以服务端为准。
- view 能力支持 `destination_modes`、`watch_later` 与目标 `destination_subdirectory_supported`；缺省旧订阅字段按 custom 显示。

`useDestinationPreview` 使用独立请求槽、180ms 输入合并、AbortController 和代次 / 输入签名检查；切来源、账号、目标、方式、目录或离开步骤 / 关闭编辑均取消等待，不采用迟到成功或错误。失败保留编辑内容，可直接重新预览。
