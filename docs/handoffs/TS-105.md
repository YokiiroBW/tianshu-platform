## 行为与边界

异步 HTTP 入口的完整本地数据库操作交给 LocalWork：4 线程、最多 16 个执行或等待项，满载立即拒绝。单事务留在同一工作函数，ContextVar 随调用传播；已运行工作在调用者取消后仍占容量直到真正结束，尚未启动的排队工作可取消，不重放命令。覆盖会话权限、模型配置、设备读写台账、来源 dispatch、对话提交、任务/资产/人格读取。模型管理通过调用作用域的写守卫，在取得权威数据库写锁后再次确认会话与解锁状态；HA 在发送台账等待结束后、实际网络调用前同步复核会话与设备解锁；内部端口共用执行边界。

原匿名 GET session 可占满共用的 128 项，持续十分钟拒绝真实登录。现匿名 challenge 单独 32 项，满时逐出最老且未在验证的匿名项；已认证会话独立 128 项，不被匿名流量逐出。login_lock 内正在验证的唯一 challenge 暂时固定，完成/失败/取消后解除。保留 Cookie/Origin/CSRF、真实密码验证及登录限流。尚未开始认证的 challenge 仍可被逐出并重新获取，不宣称网络级抗 DDoS。
