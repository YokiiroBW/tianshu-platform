# 天气与当地时段显示修复

Platform 本地开发基线 `099cbf573399562c816e337904915915408842b2`，分支 `codex/comfy-deep-20261005`。本轮未推送、部署或配置真实天气服务。

## 变更与复用

- 生活天气卡仅显示读数、位置、更新时间及失败时重试；移除配置入口、和风天气链接和归因 URL。原 API Host／API Key／位置搜索／选择表单移到“任务与设置 → 位置与天气”（`#/settings/9`），旧段索引不变。归因及接入说明集中在此页，URL 以来源域名显示。
- `WeatherSettings` 是原表单的唯一实现，旧生活页 dialog 与相应样式已移除。`useWeather` 共用当前投影、时区校验及失败处理，继续调用原 `weather/*` API 和加密凭据目录，不增加后台配置存储或权限。原授权仍要求可读真实角色；无角色时保持空选择和说明，不伪造 actor 配置。
- 按[和风官方条件代码](https://icons.qweather.com/icons/)映射晴／多云／阴／雨／雷雨含冰雹／雪／雨夹雪／雾霾／沙尘；406、456 为阵雪。晴与多云按显示当地小时切换日月图；没有代码时以天气文字回退，无法识别时使用中性未知图标。雨夹雪为同风格云、雨点及雪花 SVG。
- 数字钟旁新增七态代码原生 SVG：00–05 深夜、05–07 清晨、07–11 早晨、11–13 中午、13–17 下午、17–19 傍晚、19–24 夜晚。图像表示当地时段，未声称真实日出／日落。保留数字时间、日期、时区及下方原有“此刻”大图。
- 时段图、天气日月与数字钟共用服务器时间和显示时区，IANA 名称不可用时支持有效 UTC 偏移回退。角色切换沿原挂载键清除旧天气及显示时区；日程时区、进度与推进逻辑不变。
