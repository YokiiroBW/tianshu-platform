# TS-184 内置源仓库与自动更新交接

2026-10-17。基线 `657a42b0711c48e4860d7dd30d0cf44bf2adca5b`；分支 `codex/ts-184-book-source-warehouse`。最终产品提交和本地集成状态由根 `docs/development/tasks.json` 的 TS-184 与同号开发记录保存。交付状态仅为本地实现/验收，不代表 NAS 上线。

## 实现

“订阅 → 书籍订阅 → 书源管理 → 打开源仓库”可直接浏览 yckceo 单源/合集、搜索、排序、分页、跨页选择及查看详情，添加时选择自动更新频率。原站 HTML 由后端解析为字段，复用天枢 Drawer 和媒体控制器，不执行远端页面脚本、不生成临时短链、无需外部复制或新增登录。

后端 `books/warehouse.py` 负责站点页面与稳定链接识别，`Sources.save_feed/refresh_feed` 复用原有规则订阅、Repository、回执及后台扫描。没有新数据库、迁移或依赖。单源与合集均默认每日更新，可暂停、恢复、调整频率、立即更新；重复添加复用已有订阅，不重置本地启停/暂停/频率，也不无故改变订阅版本。尚未初次导入时修改频率仍会立即进入到期扫描。

手动链接兼容 JSON、详情页、阅读一键导入和仓库原始批量 JSON；HTTP/HTTPS/默认端口的同一仓库条目统一识别。远程规则集合单独使用 32 MiB 响应预算及 25 秒套接字超时，章节/封面保持原预算。空规则数组/null 按空对象处理；不同资源类型与坏规则逐项报告；展示新增、更新、未变、跳过数量及下次检查时间。“规则已同步”与书源实际可用分开。

## 边界和交接

仓库订阅跟踪同一条目 ID；作者另外发布的新条目不会自动替换。页面结构变更或网络暂时不可用时会明确失败并允许重试，本地规则仍保留。Reader3 引擎原有 WebView/交互登录/Android API 等覆盖边界不变。没有接入听书、音文对齐、真实书站账户，也没有推送、Linux 镜像构建或 NAS 部署。

分配工具因协调检出已有未跟踪 `build/` 拒绝，已保留原文件并按精确基线建立独立 worktree，登记原有上下文/租约；根已有混合修改不纳入产品提交。产品手册见 `docs/platform/books.md`。下一次授权发布时随 TS-183 书籍功能一起部署并验证 NAS 挂载及实际使用。
