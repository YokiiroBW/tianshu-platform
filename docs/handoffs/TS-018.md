## 2026-09-17 验收返修：会话失效与迟到回答

协调复验（`docs/development/reviews/round4-integration-2026-09-17.md`）发现的具体阻断：**双标签页
撤销会话时，任务中心的轮询被后台拒绝（403），但旧的记录仍然留在页面上**——轮询的 `catch` 吞掉了
鉴权失效，没有清空记录/详情/分页，也没有更新会话；“退出登录后不再显示任何操作记录”原来只在
“导航离开又回来”时成立。复现 `.runtime/review018.spec.ts`：退出 1，`POLL_STATUS=403`，断言 0 条
实际 1 条。

修的是**请求生命周期**本身，不是给这个场景打补丁：

- 失败分两类，判据是后台真实状态：401/403（`unauthorized` / `session_expired` / `forbidden`，
  含 CSRF 与 Origin 拒绝）是**会话没了**——清空记录、详情、来源与分页游标，重读一次会话，显示
  “登录已失效，请重新登录”与登录表单；传输错误或 5xx 是**这次读取失败**——保留旧快照并明确标注
  “下面仍是上次成功读取的快照；恢复后这里会自动更新”，不显示登录表单，也不装作刷新成功。
- 迟到的回答不能写回：每个请求带筛选、会话代号与槽位（列表/详情/轮询）三个身份，回答回来时
  只要有一个不是当前值就丢弃；换筛选在触发的同一刻记录，早于任何 `await`；同一槽位的新请求
  取消上一个；离开页面与会话失效都会取消在途请求，会话失效后不再轮询。
- 键盘焦点不丢：会话失效时若焦点在正在被移除的详情里，焦点回到任务中心面板。
- 轮询的写回顺手修对了：轮询读的是最新一页，它带回的“面板从未显示过”的记录现在落到列表最前面
  （按后台返回的顺序），已显示的记录保持原位、换成更新的说法，且一条记录不会被列两次——返修中先
  写出的 `absorb` 曾把新记录同时前置又追加，被新回归当场抓住并改正。

## 做了什么

原来“设置 → 任务”只有一个入口说明。本卡把它变成可用的操作中心：只读投影各责任模块**已经
持久化**的真实操作，带分页、状态筛选、详情、更新时间、责任模块与证据。

- 新增 `services/platform/tasks.py`：五个状态（`accepted / in_progress / observed / unknown /
failed`）、固定排序 `(整数秒, task_id)` 倒序、绑定排序与筛选的游标（含水位线）、按需重读的
  详情、来源状态与未接入声明。**不新建第二套执行库**：`platform.home` 读
  `<db>.home-controls.sqlite` 的 `control_intents`；`platform.models` 读权威库 `audit` 与
  `configs` / `native_configs`，加上 `<db>.web-models.sqlite` 里没有变成权威版本的领取记录。
- `services/platform/home.py`、`services/platform/web_models.py` 各加只读端口（`history`、
  `history_count`、`control_record`、`publications`、`ledger_state`、`ledger_count`、
  `version_record`、`intent_record`），不改任何既有写入路径与状态机。
- `services/platform/web_console.py` 注册 `POST /api/web/tasks/{view,detail}`，复用真实
  Cookie/CSRF/Origin/Sec-Fetch-Site 与读后会话复核；不需要 `models/unlock` 或 `home/unlock`。
- 网页设置第 0 段换成 `TasksPanel`：登录引导、来源块（含“未接入”理由）、状态/来源筛选、
  “加载更多”游标分页、详情展开（按需重读、Esc 收起并把焦点还给列表）、15 秒可见性暂停轮询、
  真实空状态。`tasks.css` 只用既有令牌，640px 断点适配窄屏。
- 取消按事实处理：设备控制 `executor_does_not_cancel`（已发出的指令不撤回、不自动重发），
  模型发布 `recorded_fact`（发布新版本而不是抹掉记录）。两边都只有解释，没有按不动的按钮。

## 证据与诚实边界

- 五档状态互不折叠：受理、执行中、已观测、未知、失败在列表里各是各的细轨与依据文字。
- 没有正式任务合同的产品（`companion.core`、`assets.remote`、`resources.download`）与没有可投影
  操作台账的 `platform.dialogue` 显示“未接入”，并写明理由；来源台账读不到显示“无法读取”，同时
  保留另一条流已经读到的记录，绝不把读失败显示成空白。
- 并发下不丢事实：遍历期间新写的记录比游标更新，只会出现在下一次“第一页”，不会插进遍历中间，
  也不会重复（`test_a_changed_record_and_a_new_record_do_not_confuse_a_cursor`）。
- 未知结果不猜：设备控制拿不到回执就是“未知”，重新读取任务中心不会触发任何重发
  （`test_an_unreadable_receipt_is_unknown_and_is_never_resent` 断言服务调用次数不变）。
- 退出登录后任务中心不显示任何记录（后端 401 `session_expired`，浏览器用例同样断言）。
- 会话失效与迟到回答（2026-09-17 返修）：401/403 是会话没了要清空并重新登录，传输错误/5xx 是
  这次读取失败要保留旧快照并标注；旧筛选、旧会话与离开页面之后的迟到回答都不得写回。四项浏览器
  回归与一项后端契约回归覆盖；`TasksPanel.tsx` 还原成返修前版本时这四项全部失败。
