## 变更

- `bot_connections` 只接受预登记的插件槽位、精确会话和作者 Sources entry；服务端的受限 platform principal 负责 `register_input` 与 `dispatch`。每连接随机 Bearer 只存摘要；默认停用，停用拒新事件和领取，轮换令旧令牌立即失效。
- 新建 `<database_path>.bots.sqlite` schema 1，保存连接、事件去重意图和回复台账。入站事件先落 unknown 意图，后请求 Core admission；回执 unknown 不自动重放。回复经现有 `/internal/v1/conversation/send` 收件、插件 claim、原 SDK ACK、Core `reply-status` 查询；只有 SDK 给出实际消息 ID 才记录 sent。一次领取后不再分发第二次；超时或停用保守记 unknown，同 attempt 的晚到 ACK 可补全事实。
- 同一渠道会话及角色仅一个启用 reply owner。`/api/web/bots/*` 走既有 Cookie/CSRF/Origin 会话，写操作需要管理员密码短时解锁及 `bot.manage` action。设置页展示预登记槽位、连接状态、最近事件、台账计数、一次性令牌及停用/轮换操作。
- sidecar 纳入可选运行健康检查。部署说明与两插件合成设置片段位于 `docs/platform/`。
