# 用户档案统一入口

将 `#/memory/0` 从记忆计数页改为用户档案，侧栏命名“用户”。身份目录独立于画像：复用 QQ profiles 与观察 discovered，已收到消息但没有画像的人也可出现。目录支持名称、QQ、别名搜索，私聊/群成员筛选和明确标注的分页范围。按人物展开概览、共享画像、收到的消息、回复权限、关系与好感；角色或人物切换取消旧请求。

复用既有 Memory 共享画像授权，不把入站消息当长期记忆，不开放他人私有记忆。群画像、账号关联说明、本人记忆保留在同一用户空间。关系面板接收选定角色与人物并从既有目录解析分页；原陪伴入口和 QQ 设置的重复目录收拢为跳转，QQ 管理身份授权与回复许可继续分开。

新增 `bot-observation/private-access` 仅针对已发现私聊联系人，复用既有锁、版本、幂等回执、密码解锁和策略下发。白名单只增删此人；黑名单只移除/加入此人；首次开启只将所选联系人加入白名单。保留其他用户、群策略和观察设置，不静默改变已有账号默认回复角色。没有新数据库、迁移或依赖。
