# 模块与视觉接入约定

TS-010 固定的本地前端约定，不是跨产品网络合同。

## 挂载

`apps/web/src/app/modules.ts` 是唯一导航元数据与懒加载入口。模块 ID 稳定用于 hash 地址；二级页面用从 0 开始的段号，如 `#/settings/1`。无效模块或段号显示不存在页面，不静默打开其他业务页。改变二级排序时维护旧地址兼容；段号不是后端 ID。

工作台、设置和小屋有独立 lazy 页面；其余工作区共用 `UnavailablePage`，不预建全部业务空壳。模块默认导出 React 页面，协调者在 registry 和 App 页面选择处显式挂载。不挂载第二个 React 根、不接远程模块、不另写 URL 解析。当前没有通用插件系统。

`PageBoundary` 处理导入/渲染失败并保留壳和导航；`Suspense` 展示实际等待。导入失败用整页重载恢复，避免 `React.lazy` 缓存拒绝导致伪重试。路由变化卸载旧页面，焦点移到主内容；抽屉 Escape 后回到触发点。模块异步请求自行处理错误，不假定 React 边界捕获所有异步异常。

小屋只改 `src/features/room/`；TS-011 可以替换 `RoomPage` 内部。渲染器不导出到壳。引入画布后模块负责卸载清理、隐藏时暂停高频绘制、清除订阅和释放图形资源。本次没有 renderer，不能据此宣称图形清理或手机帧率已验收。

## 状态与服务

当前没有跨服务客户端、HTTP 地址、凭据输入、业务权限或业务存储。接入准备列表是静态用途说明，不是连接登记；各项均“未配置”。搜索无结果是真实筛选空状态。工作台没有未知数量的假 0 值、假活动、假角色或成功回执。

接入前由合同负责人发布 schema、实例和双方验收。浏览器经平台同源聚合，由责任方授权和版本写入。异步请求需要取消/过期响应保护、来源和 observed_at、错误保真，以及拒绝/空/超时/冲突测试。不猜 I01–I18 URL，不回退示例成功。夹具只用于明确标注的隔离测试。

## 唯一令牌来源

`src/design/tokens.css` 包含浅深颜色、正文/毛玻璃表面、字体、间距、圆角、焦点、层级和动态时长。提取 management-v2 银蓝/淡紫/浅粉和主要文字色；正文加实为不透明表面。没有平行 TypeScript 数值副本或生成器。

业务 CSS 用语义变量，局部几何尺寸可留在组件；不复制渐变、阴影、状态色。系统减少动态优先；外观偏好只存此浏览器，禁用存储时当前页面仍可操作。减少透明度令牌和系统媒体查询均可用。

`StatusRail` 是展示组件，调用者提供文字与核定 tone，不根据自由文本猜容器状态，不承担 Docker 原始枚举映射。

| tone   | 证据要求               | 表达                               |
| ------ | ---------------------- | ---------------------------------- |
| blue   | 已确认运行且无已知故障 | 蓝实线；健康未知仍单列未知         |
| yellow | 处理中或待核对         | 黄断续细轨；说明处理事项           |
| red    | 有当前证据支持异常     | 红轨；保留运行状态和原因           |
| gray   | 非活动或无法确认       | 灰轨；区分停止、暂停、离线、未同步 |

`selected` 只改底色，不改细轨。未来容器列表分别呈现运行、健康、来源、观测时间；未知不显示健康通过。生产网页只使用真实未配置语义，不放测试容器。

后续记忆保持主题簇和按需详情，同时提供列表/键盘入口；日记保持日期目录与正文，未授权不取正文、摘要或插图。本次不渲染星图、日记样例或小屋画面。
