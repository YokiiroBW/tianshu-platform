# 章节听书与陪伴阅读

在“订阅 → 书籍订阅 → 听书设置”选择 Edge、Fish Audio 或本地接口。Edge 使用在线服务，无需填入密钥；Fish 需要自己的 API Key、模型和音色，必须手动选择后才会调用；本地服务的请求格式见[接口说明](book-audio-local-api.md)。更换播放倍速不会重新生成音频，修改生成音色或语速会形成新的缓存版本。

打开已下载书籍的阅读器，展开“提前生成听书音频”，选择当前章节或所有已保存正文，计算待生成章节后开始生成。界面显示新增章节、字符量和可复用音频。生成可暂停、继续；失败任务保留已完成片段。外部服务已收到请求但结果不明时停止自动重发，由用户手动重试。

勾选“追更后自动生成新增章节”后，现有章节作为起点，后续正文下载完成才加入音频队列。开启追更不会自动补生成全部历史章节。旧正文发生修改时保留原音频及对应文字，不自动重新消耗额度；换书源、修改书籍元数据不会导致相同正文重复合成。

音频就绪后可在阅读器播放、拖动进度、调整播放倍速，或点击高亮段落跳到对应时间。Edge 和 Fish 优先使用提供方时间戳；不能可靠匹配时按实际分段同步。相同音色的下一章已生成时自动连播，缺章处停止，避免跳过未生成章节。阅读进度保存后可继续阅读。

书库目录可供主人已授权角色在私聊中了解；未开启陪读时不共享当前阅读位置。阅读器中选择角色并开启“陪伴阅读”，才提供当前书名、章节、位置及最多800字已读片段。关闭开关、关闭阅读器、隐藏页面、退出登录或心跳超时后停止共享。重新打开阅读器默认关闭陪读；同一阅读器内换章保留选择。群聊不读取私人书库，翻页不自动调用模型或发送消息，书内内容不自动写入记忆。

每章保存 MP3 和同名 JSON 时间轴，路径沿用书库的“类别/作者/书名/audio/音色版本/章节ID”。已生成文件可长期保存在 NAS，播放不会调用语音 API。全局片段缓存位于书库 `.tianshu-audio-cache`，用于恢复与复用。
