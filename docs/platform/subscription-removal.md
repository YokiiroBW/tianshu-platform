# 删除媒体订阅

视频订阅、书籍“我的订阅”、音乐“本地歌单”和漫画“订阅追更”均提供“删除订阅”。删除后列表更新，并停止今后的定时扫描和自动新增下载。

已经下载的文件、AssetLibrary归档、书库和阅读进度保留；已入队任务继续执行，可在下载中心单独取消。音乐中已发布的Navidrome歌单保留，天枢不再自动同步该订阅。重新订阅可复用已有内容，仍按原功能刷新目录和整理成品。

删除沿用各领域`subscriptions/control`或`music/playlists/control`的`action=remove`，要求当前修订号，使用原幂等回执。内部保留removed快照和递增修订，撤销扫描租约，阻止迟到结果恢复订阅或创建新下载；不删除媒体、任务和归档回执。书籍已有remove接口保持兼容。完整验证范围见[TS-213交接](../handoffs/TS-213.md)。
