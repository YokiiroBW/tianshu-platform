# 漫画订阅

入口：订阅 → 漫画订阅，`/#/subscriptions/9`。使用现有控制台登录、媒体任务库、加密连接、下载中心与后台租约。视频引擎未配置时也可使用漫画功能。

## 首版流程

1. 连接现有 Suwayomi，读取已安装源；天枢“下载源”页面管理插件安装和每日更新，源账号登录沿用 Suwayomi 界面。普通漫画与私有收藏分别浏览。关键词结果按作品/作者/画师核对，来源只返回热门列表时不会直接当作命中；明确不提供搜索的源允许读取当前目录页后筛选，并标注来源模式。
2. 进入来源版本详情，读取目录、预览前3页，可修改作品名/作者/画师/语言/方向/简介。不同来源、译者版本独立保存，不将同名作品的页面混合。人工编辑字段保留。
3. 选择章节下载，或订阅全部/最近若干章/仅今后新章。支持暂停、恢复、调整周期和立即检查。源移除旧章时保留本地目录身份及归档阅读入口，不删除已有文件。
4. NAS导入支持一组自然排序图片，或每章一个图片文件夹/CBZ/图片ZIP。用户明确选择一部作品目录；混合布局、重复编号、损坏图片或不安全ZIP会给出具体原因。原输入只读。
5. 原图按字节封装为ZIP_STORED的CBZ，附ComicInfo.xml，不重新编码或同时生成PDF。写前/写后校验图像、页数、CRC与逐页SHA256。成品按作品/语言来源版本/章节及内容版本路径不可变发布；同路径不同字节拒绝覆盖。
6. AssetLibrary完整读取NAS文件后，提交真正目录/entry/native/content证据和持久回执。随后扫描Komga，按精确库/物理路径/大小/页数核对，返回其原生阅读入口。下载、资产纳管、阅读可用分阶段展示。

首版不新生成漫画EPUB，也不实施阅读3图片规则。已有文件和阅读进度不迁移、不删除。Suwayomi使用GraphQL控制与同源图片代理；不加入它的收藏库、不改它已有的全局追更/下载设置。

## 恢复与边界

- 来源ID作为字符串保存；内部实例ID仅用于寻址。章节身份由来源作品、章节地址和版本组成，章节号不作唯一标识。
- 已验证页面持久保存在天枢私有暂存区；恢复只获取缺失页面。取消和失败保留可恢复资料。归档与Komga双回执确认后回收该任务的私有暂存，原输入和最终CBZ保留。
- AssetLibrary调用使用稳定操作键。响应丢失先查询原键；尚未完成的观察按同键同意图恢复。HTTP200、上传完成、文件存在或PendingReview都不算正式资产归档。
- 普通HTTP读取有界；完整AS观察POST与服务端30分钟预算对齐。单页最多64MiB，单章最多4GiB/10000页，一次本地导入最多2000章。目录完整只能证明已提供页面完整，不证明出版物没有缺页。
- 源插件错误、网站验证、代理断连会逐源报告。源可用性不能由离线夹具或Suwayomi服务探测成功代替。
- 连接秘密由现有Accounts密钥加密，前端只得已保存状态；AS支持指定CA证书并保持HTTPS验证。预览图片必须通过当前控制台会话。

### NAS 专用写入进程

同一 Platform 镜像使用独立入口 `python -m services.platform.media.comics.publisher_service --settings /etc/comics-writer.json`。部署配置只含 `targets`（comic-main/comic-adult 对应容器内两个输出根绝对路径）、`socket`（独立共享卷内路径）、`client_uid`（10001）。进程以1654:10001运行，仅两处新输出根可写，不挂旧Documents、平台数据库或服务凭据。平台仍以10001运行；原Cartoon由下述输入角色只读访问。共享socket卷在平台侧只读，socket权限0660，服务端用Linux SO_PEERCRED核对连接进程UID。没有网络监听或新访问令牌。

平台漫画设置的 `publisher_socket` 指向该socket，缺省为空时沿用同进程本地发布（用于同UID部署及开发）。部署设置会随目标快照保存在任务中，网页保存其他设置不会清除它。连接探测同时返回写入进程状态。正式两个文件角色保持4b20657/ca01镜像；主平台已更新至a26f54f/a044da3，文件协议未变，无需重建文件角色。主平台两socket目录挂载只读，文件角色采用NAS支持的cpu_shares=256和512MiB内存限制。

专用进程只处理已生成CBZ的传输和不可变发布，不承担订阅、搜索或资产索引。稳定意图键绑定目标/路径/长度/SHA；4MiB分块校验并fsync后记录进度。进程中断后截去未确认尾部，从确认偏移续传；同键不同意图拒绝。完整SHA通过后复用现有volume lock和原子create-if-absent，删除暂存硬链接、同步目录，再给完成回执。已存在的不同字节永不覆盖；发布后回执丢失会核对同一文件并恢复，AS观察前最终文件只剩一个硬链接。AS仍从原Documents只读挂载读取，不跨挂载别名。

真实中断/断点/同inode恢复、Btrfs只读lease与正式AS/Komga验收依据见[交付记录](../handoffs/TS-197.md)。

### 旧图片目录只读输入

实机Synology ACL仅允许原NAS用户1026等既有身份，平台10001无法直接读取旧漫画。输入角色使用相同镜像的 `python -m services.platform.media.comics.source_service --settings /etc/comics-inputs.json`，以1026:10001运行，只挂Cartoon只读和独立socket卷；无生产数据库、外部连接凭据或可写漫画目录。配置只含 `directory`、`socket`、`client_uid`，平台设置 `import_socket` 后复用原浏览/章节发现/自然排序/输入变更检查，通过Unix socket流式读取原图或旧CBZ到既有私有缓存。逐页断点、校验、封装与归档仍归原工作队列，不建立第二套下载/订阅系统。两类文件服务共用Linux peer UID与socket生命周期实现，安装不依赖新增DSM账号或递归修改旧文件ACL。

AS侧保留现有Documents库和真实原生根。其目录链需要read/search与inotify，不能仅授x权限。AS部署单写者已对Documents、Cartoon、漫画、本子四祖先各增加1654本目录只读ACE，不继承；仅两新天枢root具有自身继承写权限。原ACE与旧子树权限保留，真实native root和target均已登记。后续部署沿用现有配置，不重复添加ACL、不递归修改旧目录。

Suwayomi实机为2.3.2243、Komga为1.24.4-master；未升级。按用户明确要求停用Suwayomi旧SOCKS开关，由路由器分流。正式网页17个普通源聚合返回97个来源版本，12源可用、5源暂不可用；不代表所有插件可用。Komga专用密钥已获动作确认并保存到现有Accounts加密设置，旧密钥和其他媒体配置保持。真实最新22页、原目录13张图片、普通样本私密目标6页已通过完整归档与阅读，原序章24页保留；重复请求不产生新任务或文件。

## 扩展仓库与自动维护（TS-201）

“下载源”页面管理 Keiyoushi、Yūzōnō 与 LittleSurvival 仓库，安装全部语言的兼容插件，并每天检查新增插件和升级。普通漫画和本子/私藏沿用 SAFE 与其他内容标记的分组；安装完成、搜索验证、下载验证分别显示。源刷新支持完整分页，聚合搜索通过四个工作协程覆盖所有选定源，不再截取前100个。

复用 media documents、scan_leases、后台生命周期与 Suwayomi GraphQL。维护策略以引擎身份保存；页面控制有既有登录/CSRF/幂等回执，后台事实不递增用户控制修订号。按包名去重并固定已安装包的来源，冲突源ID不重复加载；源的本地启停、原订阅、章节身份和归档回执保留。Yūzōnō 当前索引仅包含迁移提示，作为占位项目显示并跳过，不能称新增有效插件。

Suwayomi 2.3.2243 支持插件API 1.3至1.6，但其更新先卸载旧包。天枢先下载验证目标归档、保存旧JAR，再通过顶层 Upload 变量提交文件（该版本不支持嵌套multipart变量）。安装后核对包名、版本和原源ID；回执丢失先对账，升级失败通过相同API恢复原JAR，不覆盖Suwayomi数据库。原源正在搜索、读取章节或下载图片时延后更新。缺备份不卸载旧包；失败与不可安装原因逐项保留，下轮重试，不自动删除旧源。

该版本的 `ExtensionCondition.pkgName` 虽在schema中声明，实际查询没有应用此条件。精确查询使用 `filter.pkgName.equalTo`，且适配器拒绝返回其他包名，避免错误备份或误判安装结果。实机验收必须覆盖多个已安装插件，单插件实例无法暴露此上游缺陷。

运行容器需要只读绑定 Suwayomi 的 extensions 目录到 `/media/SuwayomiExtensions`；也可用 `TIANSHU_COMIC_EXTENSIONS_DIRECTORY` 指定只读位置。只读取插件JAR，不需要Suwayomi数据库、账号配置目录或Docker控制权。暂存和恢复副本位于既有 `.comic-content/extensions` 下。部署显式启用维护；页面可暂停或立即检查，恢复时继续核对未完成操作。

上游未知章节页数可能为-1；目录保存边界统一为0，预览继续按前三页实际读取，实际页数由下载结果补全。

## 下载源实测记录（TS-203）

下载源页可按中文（含简繁语言变体）及验证状态筛选，逐源显示入口、搜索、目录、预览、完整下载、封装、AS归档和Komga阅读结果。记录来自真实操作，包含时间、样本目标、最近成功和最近失败；只探测入口的源，其内容功能继续显示未验证。零匹配会同时显示返回条数，不能把返回热榜当成命中。源健康事实更新不改变启停修订或原订阅。

失败区分站点地址配置、登录/验证、403/404、DNS、超时、WebView、解析、内容筛选和插件接口不兼容。归档或阅读失败保留之前已经成功的下载记录。页面不输出上游原始堆栈、带令牌地址或凭据；不会因一次错误自动停用源或删除已有数据。

2026-10-19已完成110中文源的分层核对：52个源实际搜索（45响应成功，其中25有匹配、20零匹配），其余58个只进行入口探测。腾讯/拷贝/如漫画3个非露骨样本共241页完成下载、无损CBZ、持久AS回执及Komga原页核对；包子Plus因缺少Bitmap接口失败，原样保留失败任务。正式登录后的分组、中文/验证状态筛选、分阶段错误与历史、书库阅读链接及原追更周期均已核对。当前失败筛选不包含已恢复的历史失败，历史原因仍保留在对应源记录内。完整范围及例外见[TS-203交接](../handoffs/TS-203.md)，不将这些样本推断为全站所有作品或成人内容源都可下载。
