# 漫画订阅

入口：订阅 → 漫画订阅，`/#/subscriptions/9`。使用现有控制台登录、媒体任务库、加密连接、下载中心与后台租约。视频引擎未配置时也可使用漫画功能。

## 首版流程

1. 连接现有 Suwayomi，读取已安装源；天枢“下载源”页面管理插件安装和每日更新，源账号登录沿用 Suwayomi 界面。普通漫画与私有收藏分别浏览。关键词结果按作品/作者/画师核对，来源只返回热门列表时不会直接当作命中；明确不提供搜索的源允许读取当前目录页后筛选，并标注来源模式。
2. 进入来源版本详情，读取目录、预览前3页，可修改作品名/作者/画师/语言/方向/简介。不同来源、译者版本独立保存，不将同名作品的页面混合。人工编辑字段保留。
3. 选择章节下载，或订阅全部/最近若干章/仅今后新章。支持暂停、恢复、调整周期和立即检查。源移除旧章时保留本地目录身份及归档阅读入口，不删除已有文件。
4. NAS导入支持一组自然排序图片，或每章一个图片文件夹/CBZ/图片ZIP。用户明确选择一部作品目录；混合布局、重复编号、损坏图片或不安全ZIP会给出具体原因。原输入只读。
5. 原图按字节封装为ZIP_STORED的CBZ，附ComicInfo.xml，不重新编码或同时生成PDF。写前/写后校验图像、页数、CRC与逐页SHA256。成品按作品/语言来源版本/章节及内容版本路径不可变发布；同路径不同字节拒绝覆盖。
6. AssetLibrary完整读取NAS文件后，提交真正目录/entry/native/content证据和持久回执。随后扫描Komga，按精确库/物理路径/大小/页数核对，返回其原生阅读入口。下载、资产纳管、阅读可用分阶段展示。

首版不新生成漫画EPUB，也不实施阅读3图片规则。已有文件和阅读进度不迁移、不删除。Suwayomi使用GraphQL控制与同源图片代理；不加入它的收藏库、不改它已有的全局追更/下载设置。

## 恢复与边界

- 来源ID作为字符串保存；内部实例ID仅用于寻址。章节身份由来源作品、章节地址和版本组成，章节号不作唯一标识。
- 已验证页面持久保存在天枢私有暂存区；恢复只获取缺失页面。取消和失败保留可恢复资料。归档与Komga双回执确认后回收该任务的私有暂存，原输入和最终CBZ保留。
- AssetLibrary调用使用稳定操作键。响应丢失先查询原键；尚未完成的观察按同键同意图恢复。HTTP200、上传完成、文件存在或PendingReview都不算正式资产归档。
- 普通HTTP读取有界；完整AS观察POST与服务端30分钟预算对齐。单页最多64MiB，单章最多4GiB/10000页，一次本地导入最多2000章。目录完整只能证明已提供页面完整，不证明出版物没有缺页。
- 源插件错误、网站验证、代理断连会逐源报告。源可用性不能由离线夹具或Suwayomi服务探测成功代替。
- 连接秘密由现有Accounts密钥加密，前端只得已保存状态；AS支持指定CA证书并保持HTTPS验证。预览图片必须通过当前控制台会话。

### NAS 专用写入进程

同一 Platform 镜像使用独立入口 `python -m services.platform.media.comics.publisher_service --settings /etc/comics-writer.json`。部署配置只含 `targets`（comic-main/comic-adult 对应容器内两个输出根绝对路径）、`socket`（独立共享卷内路径）、`client_uid`（10001）。进程以1654:10001运行，仅两处新输出根可写，不挂旧Documents、平台数据库或服务凭据。平台仍以10001运行；原Cartoon由下述输入角色只读访问。共享socket卷在平台侧只读，socket权限0660，服务端用Linux SO_PEERCRED核对连接进程UID。没有网络监听或新访问令牌。

平台漫画设置的 `publisher_socket` 指向该socket，缺省为空时沿用同进程本地发布（用于同UID部署及开发）。部署设置会随目标快照保存在任务中，网页保存其他设置不会清除它。连接探测同时返回写入进程状态。正式两个文件角色保持4b20657/ca01镜像；主平台已更新至a26f54f/a044da3，文件协议未变，无需重建文件角色。主平台两socket目录挂载只读，文件角色采用NAS支持的cpu_shares=256和512MiB内存限制。

专用进程只处理已生成CBZ的传输和不可变发布，不承担订阅、搜索或资产索引。稳定意图键绑定目标/路径/长度/SHA；4MiB分块校验并fsync后记录进度。进程中断后截去未确认尾部，从确认偏移续传；同键不同意图拒绝。完整SHA通过后复用现有volume lock和原子create-if-absent，删除暂存硬链接、同步目录，再给完成回执。已存在的不同字节永不覆盖；发布后回执丢失会核对同一文件并恢复，AS观察前最终文件只剩一个硬链接。AS仍从原Documents只读挂载读取，不跨挂载别名。

真实中断/断点/同inode恢复、Btrfs只读lease与正式AS/Komga验收依据见[交付记录](../handoffs/TS-197.md)。

### 旧图片目录只读输入

### 单容器内置文件辅助插件（TS-332，本地候选）

统一容器可以通过既有插件宿主管理这两个文件角色，用户无需再部署独立的 inputs/publisher 容器。Platform 设置增加：

```json
{
  "plugins": {
    "comic_files": {
      "runtime_socket": "/run/tianshu/comics/control.sock",
      "defaults": {
        "import_directory": "/media/comics/input",
        "import_socket": "/run/tianshu/comics/inputs/source.sock",
        "publisher_socket": "/run/tianshu/comics/publisher/publisher.sock"
      }
    }
  }
}
```

首次配置后，原 PluginManager 按正常安装流程创建 `tianshu.comics-files` 内置包及一个默认启用实例。配置、启停、实例修订与卸载均沿用原插件台账和界面；后续停用或卸载不会在重启时被自动开启。已有启用实例重启时恢复同一实例，不另建漫画队列。没有这项配置时，不自动安装辅助插件，旧本地/外置 socket 入口仍可继续使用。

`defaults` 是成组可选的首次安装值，必须同时提供上面三个绝对 POSIX 路径。它仅在原 `comic_settings/library` 完全不存在时参与 `Settings.read`，读默认值不写数据库；首次在原漫画设置页保存时，由原 `Settings.save` 和回执/CAS落账。已存在任何设置行时不叠加默认值，即使其中socket为空或未含字段也不会覆盖。仅配置 `runtime_socket` 的旧形式保留。现有漫画和下载任务中的输入/目标快照也不改；迁移已有安装应让原设置生产者与helper沿用一致路径，不能靠这组默认值替换旧快照。

统一运行时在新临时目录 `/run/tianshu/comics/inputs` 和 `publisher` 上准备root:10001、01770权限，helper自行创建原0660 socket与lock。仅父目录0755会使降权后的helper无法绑定；不因此为NAS目录加写权、递归改ACL或给运行时加CHOWN/DAC_OVERRIDE。

插件自身不接受命令、目录、UID 或 socket 配置，也不启动通用 shell。它仅在生命周期中通过 `comics.files` 能力请求受信运行时启动/停止固定的 `comic-inputs` 与 `comic-publisher`；正式内置包来源也会复核，上传同名包不能获得这项控制。`status` 是纯读动作，动作/模型调用不能启动或停止文件角色。

运行时控制为私有 Unix socket，`POST /v1/comics/{start,stop,status}` 的唯一请求字段是 `owner`（原插件实例 UUID）。两角色命令、设置路径和 UID 由统一容器配置固定：原 `source_service` 仍为 1026:10001，原 `publisher_service` 仍为 1654:10001，Platform 仍为 10001。运行时检查连接进程 UID10001；已有两个业务 socket 的 SO_PEERCRED、只读原库、AS owner 与文件回执协议保持。控制响应仅含 `state`（ready/starting/stopped/failed）及两角色的 running/stopped/failed，不下发路径或凭据。

启动先请求 start，最多等10秒轮询真实 status，两个角色都 ready 后插件才就绪；查询状态从不启动进程。同包第二实例抢占返回409，并恢复其原期望状态，避免下一次重启抢占原实例。正常停用和宿主关闭释放自己的 owner；插件 worker 崩溃时宿主也请求停止文件角色。运行时不可达或 stop 失败时，投影保留期望状态与实际角色状态的差异并显示 error，不宣称已经停好。整个容器退出的最终进程收尾归统一运行时。

插件投影新增 `file_runtime`，用于区分插件 worker 与真实文件角色状态。关闭辅助仅关闭文件访问角色；原漫画订阅、下载和任务仍归原模块，访问不可用按原任务与重试流程报告，重新启用不绕过原断点与回执。

这项交付只实现本地接点；Linux UID 切换、统一容器控制端、真实 NAS/AS 和单容器启动验收由统一发行集成完成。512MiB仍是旧每角色内存上限，不能当成合并后的节省量。部署不会因此统一三个 UID 或递归修改 NAS ACL。

Suwayomi实机为2.3.2243、Komga为1.24.4-master；未升级。按用户明确要求停用Suwayomi旧SOCKS开关，由路由器分流。正式网页17个普通源聚合返回97个来源版本，12源可用、5源暂不可用；不代表所有插件可用。Komga专用密钥已获动作确认并保存到现有Accounts加密设置，旧密钥和其他媒体配置保持。真实最新22页、原目录13张图片、普通样本私密目标6页已通过完整归档与阅读，原序章24页保留；重复请求不产生新任务或文件。

## 下载源实测记录（TS-203）

下载源页可按中文（含简繁语言变体）及验证状态筛选，逐源显示入口、搜索、目录、预览、完整下载、封装、AS归档和Komga阅读结果。记录来自真实操作，包含时间、样本目标、最近成功和最近失败；只探测入口的源，其内容功能继续显示未验证。零匹配会同时显示返回条数，不能把返回热榜当成命中。源健康事实更新不改变启停修订或原订阅。

失败区分站点地址配置、登录/验证、403/404、DNS、超时、WebView、解析、内容筛选和插件接口不兼容。归档或阅读失败保留之前已经成功的下载记录。页面不输出上游原始堆栈、带令牌地址或凭据；不会因一次错误自动停用源或删除已有数据。

## 中文搜索与恢复操作（TS-204）

搜索界面固定中文（简繁体），后台默认空语言为zh，明确传入其他语言或all的既有API用法仍可使用。全语言插件安装、维护和原订阅不受影响。OpenCC离线转换繁简写法，标题/作者采用同一归一化；可填写最多两个其他译名或原名作为替代查询。同一来源结果去重，标题精确匹配排前，最近7天实际内容操作成功的源优先请求。单源总计90秒、最多9种不重复写法；目录回退只取同一页一次。部分写法失败会保留结果并显示不完整状态。源语言不能证明每张图片已汉化，仍显示真实来源和目录汉化组。

下载源状态在前，插件仓库与每日维护可展开；较旧的验证记录和错误处理建议直接显示。追更显示下次检查、上次成功检查新增数。章节详情通过现有队列继续失败任务，当前作品/分类/章节版本的任务才会投影，隐藏的旧任务不重新出现；复用现有页缓存和归档回执。查看详情再返回不会丢失搜索结果。验证及上线状态见[TS-204交接](../handoffs/TS-204.md)。

## 自动别名与中文版本（TS-211）

输入英文或日文原名时，先查公开书目中的漫画原名、中文名与别名，必要时用AniList名称桥接Bangumi中文资料。唯一精确对应自动扩展，同名多作品显示候选供选择；资料故障时继续使用原名/手填别名。页面显示采用的名称和出处。资料缓存有界，查询最多18种不重复写法，仍沿原四工作者、单源90秒预算；不以模型直译代替通行作品名。

中文搜索同时覆盖中文源与多语言源，目标语言过滤使用插件的当前请求参数，原作语言不会当作正文语言。已知非中文版本过滤；来源/作品/章节语种与汉化标记分别展示，未知版本可单独查看。源仅暴露全局语言偏好或缺少语种时无法保证找到全部中文内容，页面不把未知当已汉化。

详情选择中文语种及汉化组，新追更固定这个来源版本；空汉化组也精确匹配。版本过滤先于分页；原版本消失会显示原因，保留原文件并重查。旧订阅没有新版本策略时保持原行为，无批量迁移。原归档可通过“查看全部章节与已有归档”继续阅读。当前验证/发布状态见[TS-211交接](../handoffs/TS-211.md)。
